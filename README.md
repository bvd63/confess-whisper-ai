## ✨ New in v2.0.0 - Mobile & Communities

### 📱 Native Mobile Apps
- **iOS & Android Support**: True native apps via Capacitor
- **Device Features**: Camera, geolocation, push notifications
- **Hot Reload**: Fast development with live updates
- **App Store Ready**: Configured for deployment
- **Offline First**: Works seamlessly without connection

### 🌍 Location-Based Discovery
- **Optional Location Sharing**: Privacy-first location features
- **Nearby Confessions**: Discover local content
- **Privacy Controls**: Users opt-in to share location
- **Indexed Queries**: Fast location-based searches

### 👥 Community System
- **Topic-Based Communities**: Organized by interest/category
- **Join & Create**: Users can create their own communities
- **Member Management**: Roles (admin, moderator, member)
- **Community Feeds**: Filter confessions by community
- **Public & Private**: Control community visibility
- **Auto-counting**: Track members and posts automatically
